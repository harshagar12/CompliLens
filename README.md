# CompliLens (SIH26034)

**AI-Assisted Automated Legal Metrology Compliance and Inspection System**  
*Built for Legal Metrology (Packaged Commodities) Rules, 2011 (LMPC).*

---

## 📖 Project Overview

**The Problem:** 
Currently, Legal Metrology Officers manually inspect packaged commodities to verify if the manufacturer has declared all statutory information (like MRP, Net Quantity, Manufacturer Name, Customer Care details, etc.) as mandated by the LMPC Rules, 2011. This manual process is time-consuming, prone to human error, and difficult to scale across thousands of products.

**The Solution:** 
**CompliLens** is a comprehensive, AI-powered compliance platform designed specifically for regulatory officers and compliance auditors. It automates the extraction of statutory declarations from packaging artworks and rigorously verifies them against a deterministic LMPC rules engine. 

Instead of relying on LLMs to make regulatory decisions (which can hallucinate), CompliLens uses AI purely for *perception* (OCR and text extraction). The actual compliance verdict is generated by a **deterministic, version-controlled Rules Engine** that directly cites the relevant LMPC statutes.

---

## ✨ Key Features

- **Automated Text Extraction (OCR)**: Extracts key fields from packaging images (e.g., MRP, Net Quantity, Dates) using a sophisticated AI pipeline.
- **Traceable Evidence Payloads**: Every extracted field is tied to a confidence score and a bounding-box crop from the original image. Officers can see *exactly* where the data came from.
- **Mandatory Human-in-the-Loop Review (Phase 3)**: Before rules are evaluated, a mandatory review screen requires the inspector to confirm or edit extracted declarations. The system flags low-confidence extractions for manual review.
- **Deterministic Rules Engine**: The compliance verdict (`PASS`, `FAIL`, `NEEDS_REVIEW`) is NEVER produced by an LLM. It originates exclusively from a deterministic rule evaluated by the engine, citing the exact statutory clause.
- **Audit Dossier Generation**: Generates comprehensive, download-ready PDF statutory compliance reports using a Gotenberg headless-browser engine.

## 🛠️ Technology Stack

- **Backend**: Python, FastAPI, Pydantic (Data Validation).
- **Frontend**: Next.js (App Router), React, TailwindCSS.
- **AI/Perception**: RapidOCR / Gemini Vision capabilities for text extraction.
- **PDF Generation**: Gotenberg (Containerized headless Chrome for PDF generation).

## 🚀 Quickstart: Running Locally

### Prerequisites
- Python 3.11+
- Node.js 18+ and npm
- Docker (optional, but required for PDF generation via Gotenberg)

### Step 1: Start the Backend
```bash
cd compli-lens/backend

# Activate virtual environment
# Windows:
.venv\Scripts\activate
# Mac/Linux:
# source .venv/bin/activate

# Run FastAPI backend
python -m uvicorn main:app --reload --port 8000
```
*Backend API interactive docs will be available at: `http://localhost:8000/docs`*

### Step 2: Start the Frontend
The modern dashboard is located in `frontend-new`.
```bash
cd compli-lens/frontend-new
npm install
npm run dev
```
*Open your browser and navigate to: `http://localhost:3000`*

### Step 3: Run Gotenberg (Optional - for PDF reports)
If you want to generate downloadable Audit PDFs, run Gotenberg via Docker:
```bash
docker run --rm -p 3001:3000 gotenberg/gotenberg:8
```

## 🖥️ User Walkthrough (How to use CompliLens)

1. **Landing Page**: Navigate to `http://localhost:3000`. You will see the landing page showcasing the CompliLens automated extraction system.
2. **Upload Packaging**: Click "Start Inspection". Upload an image of a packaged commodity (e.g., a biscuit wrapper, soap box) or use the sample image provided by clicking "Load Sample Label".
3. **Extraction & Review**: The AI pipeline will extract the text, draw bounding boxes, and present a side-by-side review interface. 
   - **Important**: You must review and accept each extraction. 
   - Click on any field to see the exact bounding box snippet on the original image.
4. **Evaluate Compliance**: Once all fields are confirmed by the human reviewer, click "Run Statutory Evaluation". 
5. **Audit Report**: CompliLens evaluates the confirmed fields against the deterministic JSON rules engine. It will generate a final "Audit Dossier" showing exactly which rules passed and failed, citing the exact laws.
6. **Download**: Click "Download PDF" (requires Gotenberg) to generate a permanent compliance record.

## ⚙️ How to Add a New Rule (Without Touching Code)

To ensure the system scales as laws change, every rule in CompliLens is a declarative, versioned JSON file. You do not need to be a programmer to add new legal checks.

1. Create a new JSON file in `backend/engine/rules/` (e.g. `lmpc_6_1_f_dimensions.json`).
2. Adhere strictly to the JSON schema:
```json
{
  "rule_id": "LMPC-6.1.f",
  "description": "Package declares dimensions of commodity where size is relevant",
  "source_citation": "Legal Metrology (Packaged Commodities) Rules, 2011, Rule 6(1)(f)",
  "applicable_category": ["packaged_food"],
  "excluded_category": [],
  "required_field": "dimensions",
  "validation_condition": { "op": "non_empty" },
  "severity": "FAIL"
}
```
3. **Supported operators**: `non_empty`, `regex_match`, `in_range`, `lookup_membership`.
4. The engine will instantly pick up the new JSON file and apply it to all future inspections!

## 🧪 Running the Evaluation Harness & Test Suite

### Automated Unit & API Tests
```bash
cd compli-lens/backend
pytest tests -v
```

### Comprehensive Benchmark Evaluation Study
To measure how accurately the AI is extracting text:
```bash
python evaluation/run_eval.py
```
This script computes and reports:
- Character Error Rate (CER) and Word Error Rate (WER) against raw OCR.
- Per-field extraction Recall.
- Compliance Accuracy and safety-critical False-Compliance Rate.
